# AI edu · Виртуальные лаборатории

Практическая часть дипломной работы «Разработка виртуальных лабораторий по генерации учебного материала в обучающей системе». Траектория 2: педагоги не IT-специальностей.

14 виртуальных работ, в каждой преподаватель создаёт учебный материал по своей дисциплине с помощью генеративного ИИ:
**Задание → Исходные данные → Промпт → Генерация → Экспертиза → Улучшение → Портфолио**.

Модуль написан на стеке платформы AI edu (Django + DRF, React + TypeScript + Vite + Tailwind) и встраивается в неё как модуль: см. [INTEGRATION.md](INTEGRATION.md).

## Запуск

| Способ | Что сделать |
|---|---|
| Windows | двойной щелчок по `backend\start.bat` (нужен Python 3.11+), откроется <http://127.0.0.1:8000> |
| Linux, macOS | `bash backend/start.sh` |
| Docker (PostgreSQL + резервные копии) | `docker compose up -d`, затем <http://localhost:8000> |
| Разработка интерфейса | сервер как выше, затем `cd frontend`, `npm ci`, `npm run dev` → <http://localhost:5173> (запросы `/api` уходят на Django) |

Первый зарегистрированный пользователь становится администратором. Без настроек используется SQLite (`backend/aiedu.sqlite3`); для PostgreSQL заполните `DATABASE_*` в `backend/.env` (образец `backend/.env.example`).

Пока языковая модель не подключена, генерация идёт в **демо-режиме** по шаблонам. Модель подключает администратор: «Администрирование → Модели ИИ» (OpenAI, Google Gemini, Anthropic Claude, OpenAI-совместимые API). Ключи хранятся только на сервере, слушатели их не вводят. Озвучка: OpenAI TTS, ElevenLabs или синтезатор браузера.

## Что реализовано по пунктам сверки с ТЗ

| Пункт ТЗ | Что сделано |
|---|---|
| 8.2 Тьютор | группы с кодом приглашения, задания со сроками, проверка результатов по критериям, отзывы с оценкой, аналитика группы |
| 8.3 Администратор | пользователи и роли, курсы и работы (включение, порядок), критерии экспертизы (название, вес, включение), шаблоны промптов, модели ИИ с проверкой подключения, журнал запросов к ИИ, резервные копии, платформы LMS |
| 36 Экспорт | DOCX, PDF, **PPTX** (работа № 5: слайды с тезисами и заметками докладчика), Markdown, TXT; формирует сервер |
| 9, 34.4 Документы | загрузка силлабусов, лекций, учебников и презентаций (DOCX, PDF, PPTX, TXT, MD) в файловое хранилище сервера, извлечение текста, вставка в работы |
| 16 Исследовательский кабинет | поиск публикаций в **OpenAlex, Crossref и Semantic Scholar** с объединением результатов по DOI |
| 38 Безопасность | ограничение частоты запросов к API, резервное копирование по расписанию (`vl_backup`), проверка загружаемых файлов (тип по содержимому, макросы, сценарии и вложения в PDF, размер после распаковки), ключи ИИ только на сервере, JWT для внешних клиентов |
| 37 LMS | LTI 1.3 (Moodle, Open edX, Canvas, Blackboard): вход из курса LMS, открытие нужной работы |
| 31 База данных | 26 таблиц: Discipline, Course, VirtualWork, PromptTemplate, Prompt, Generation, Evaluation, Recommendation, UploadedFile, PortfolioItem, Progress, Group, Assignment, Review и др. |
| 34.1 Интерфейс | React + Tailwind в дизайне AI edu, адаптивная вёрстка (проверено на 390 px) |
| Языки | русский, казахский, английский: интерфейс, описания 14 работ, комментарии экспертизы и рекомендации, сообщения сервера; язык создаваемого материала выбирается в исходных данных |

Оценки AI-экспертизы считает сервер; интерфейс считает их так же (31 общий тестовый случай), поэтому балл виден сразу и подтверждается после сохранения.

## Роли

| Роль | Что доступно |
|---|---|
| Слушатель (преподаватель) | 14 работ, портфолио, прогресс, задания тьютора, профиль и документы |
| Тьютор | всё выше + группы, задания, проверка работ, отзывы, аналитика своих групп |
| Администратор | всё выше по всем слушателям + раздел «Администрирование» |

Роль назначается в «Администрирование → Пользователи и роли» или командой `python manage.py vl_set_role <логин> tutor|admin|teacher`.

## Структура

```
backend/
  apps/virtual_labs/      модуль (переносится в AI edu без изменений)
    models.py             26 таблиц vl_*
    views/                API: слушатель, тьютор, администратор, сервисы, LTI
    services/             экспертиза, Prompt Engine, ИИ, литература, файлы, экспорт, LTI, резервные копии
    catalog/works.json    каталог 14 работ (собирается из интерфейса: npm run catalog)
    tests/                51 тест модуля
  apps/accounts/          вход и регистрация для автономного запуска (в AI edu свои), 4 теста
  config/                 настройки автономного запуска
frontend/
  src/virtual-labs/       модуль интерфейса (переносится в AI edu без изменений)
    core/                 реестр 14 работ, Prompt Engine, экспертиза, рекомендации, демо-генератор
    pages/                каталог, работа (7 шагов), портфолио, прогресс, задания, профиль, тьютор, администрирование
    practice/             регистрация работ как практик AI edu
    locales/              казахский и английский словари модуля
  src/host/, src/i18n.tsx оболочка автономного запуска: шапка, вход, стили AI edu
  tests/                  20 тестов (Vitest)
  tools/                  сборка каталога, проверка переводов
docs/                     протокол приёмочных испытаний
INTEGRATION.md            инструкция для интегратора AI edu
```

## Проверки

```bash
cd backend && python manage.py test apps          # 55 тестов сервера (51 модуля + 4 автономного входа)
cd frontend && npm test                           # 20 тестов интерфейса
cd frontend && npm run lint && npm run build      # типы TypeScript и сборка
cd frontend && npm run i18n:check                 # все строки переведены на kz и en
```

Словарь сообщений сервера для проверки переводов обновляется командой `python tools/server-strings.py > tools/server-strings.json` в папке `frontend`.
